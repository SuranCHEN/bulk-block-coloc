## 1. 基因型：x 是什么

### 1.1 剂量（dosage）

每个 SNP 有两个等位基因，代码里叫 `a1`（计数的那个）和 `a0`。一个人在这个 SNP 上的基因型记成 **a1 的拷贝数**：0、1 或 2。这就是 dosage。

设 a1 在人群中的频率是 `p`，按哈迪–温伯格平衡：

```
P(x = 2) = p²,  P(x = 1) = 2p(1 − p),  P(x = 0) = (1 − p)²
E[x] = 2p,      Var(x) = 2p(1 − p)
```

**哈迪–温伯格平衡（HWE）是什么**：一个人的两条染色体（一条来自父亲、一条来自母亲）各带一个等位基因。如果人群随机婚配、没有强烈的选择或迁移，这两个等位基因就像从人群的“等位基因池”里**独立地各抽一次**，每次抽到 a1 的概率都是 p。于是：

- 两次都抽到 a1（x = 2）：`p × p = p²`
- 一次 a1、一次 a0（x = 1）：先 a1 后 a0 或先 a0 后 a1，`2 × p(1 − p)`
- 两次都是 a0（x = 0）：`(1 − p)²`

换句话说 x 是两次独立抛“正面概率为 p 的硬币”中正面的次数，即 `x ~ Binomial(2, p)`，所以均值 `2p`、方差 `2p(1 − p)`（二项分布的 `n·p` 和 `n·p·(1 − p)`，n = 2）。

**为什么这里要用它**（模拟本身不依赖 HWE：基因型是真实的，标准化用的是样本里实际算出的均值和标准差；HWE 只是帮我们理解两件事）：

1. **频率决定一个 SNP 的信息量。** `Var(x) = 2p(1 − p)` 在 p = 0.5 时最大（0.5），p = 0.05 时只有 0.095。效应估计的方差约为 `se² ≈ Var(y) / (N · 2p(1 − p))`，所以稀有变异的 se 大、估计不稳。这就是因果 SNP 要求 MAF ≥ 0.05 的原因，也是 coloc 需要输入 MAF、6.1 节算 ABF 时 `V = 1 / (N · 2p(1 − p))` 的来源。
2. **质量控制。** 真实数据里某个 SNP 的三种基因型比例如果严重偏离 `p² : 2p(1−p) : (1−p)²`，通常是基因分型出错（例如把杂合子误判成纯合子），所以 QC 时去掉 HWE 检验 p < 1e-6 的 SNP。

**MAF（minor allele frequency，次要等位基因频率）** 是两个等位基因中较少见的那个的频率，`MAF = min(p, 1 − p)`，所以总在 0 到 0.5 之间。

为什么取 min：哪个等位基因叫 a1（被计数）是人为约定，换一个计数，p 就变成 1 − p，但这个 SNP 本身没有任何变化。决定一个 SNP “有多少变异、能提供多少信息”的是 `2p(1 − p)`，它对 p 和 1 − p 是对称的。取 min 就得到一个和计数约定无关的量：MAF = 0.5 表示两个等位基因一样常见，MAF 越小越稀有。

MAF 的用处：

- **衡量信息量**：`Var(x) = 2·MAF·(1 − MAF)`，MAF 越小，人群里携带少见等位基因的人越少，效应越难估准（se 越大，见上面第 1 点）。
- **筛选**：太稀有的 SNP 在 1,000 人的 eQTL 里可能只有几十个携带者，单 SNP 回归不稳定，所以 QC 和因果 SNP 都要求 MAF ≥ 0.05。
- **coloc 的输入**：coloc.abf 需要每个 SNP 的 MAF，用来在没有给出表型标准差时估计它，以及计算贝叶斯因子。

**QC（quality control，质量控制）** 就是在分析之前把不可靠的 SNP 筛掉。这些条件都是为了留下“合格”的 SNP。本项目的 UKBB 基因型在交接时已经用 PLINK 做过下面的 QC（命令见 `data/genotype_reference/README.md`），1000 Genomes 参考人群也做过类似的筛选：

| 条件 | 筛掉什么 | 为什么 |
|---|---|---|
| MAF ≥ 0.05 | 稀有变异 | 携带者太少，效应估计和 LD 估计都不稳定 |
| 缺失率 ≤ 2% | 超过 2% 的人没测出基因型的 SNP | 缺失多通常说明这个位点分型质量差；缺失还要靠插补补上，引入误差 |
| HWE p ≥ 1e-6 | 三种基因型比例严重偏离 HWE 的 SNP | 严重偏离多半是分型出错（上面第 2 点）；阈值定得很严（1e-6），只去掉明显有问题的 |
| 去掉回文 SNP | A/T、C/G 这类 SNP | 见下 |

**回文 SNP（palindromic / ambiguous SNP）**：DNA 是双链，A 和 T 配对、C 和 G 配对。同一个 SNP 从另一条链读，碱基都要换成互补碱基。普通 SNP 换链后能看出来：A/G 在另一条链上读作 T/C，和 A/G 不一样，一眼就知道链反了。但如果两个等位基因本身互补，例如 A/T，换到另一条链读作 T/A，还是同一对碱基；C/G 也一样。这种 SNP 叫回文 SNP。

问题在于：两个数据集（UKBB 和 1000G）如果用的链方向不同，A/T 型 SNP 的 “a1 = A” 在另一个数据集里可能其实对应 T，而光看碱基分不出来。对错了，等位基因就反了，LD 的符号随之反了（1.3 节）。所以最稳妥的做法是直接去掉回文 SNP。UKBB 这一步去掉了约 5,000 个回文 SNP，对齐 1000G 时就没有这种歧义。

### 1.2 标准化

模型里用的是**样本内标准化**后的基因型：

```
x̃_kj = (x_kj − 2p̂_j) / sd_j        （k 是人，j 是 SNP，p̂、sd 都在这个样本里算）
```

标准化以后，每个 SNP 的均值 0、方差 1。这样做的好处是：效应 `b_j` 的含义变成“基因型每增加一个标准差，表型变化多少个标准差”，于是 **`b_j²` 直接就是这个 SNP 解释的方差比例**，不受等位基因频率影响。后面所有关于 h² 的推导都依赖这一点。

**过程（对每个 SNP 分别做，两步）**：

1. **中心化**：减去这个 SNP 在样本里的平均剂量 `2p̂`（p̂ 是样本里 a1 的频率），让均值变成 0；
2. **缩放**：除以样本里的标准差 sd，让方差变成 1。

**注意：标准化不会让 x 变成正态分布。** 它只是把每个值减同一个数、再除以同一个数，分布的形状不变：标准化以后 x̃ 仍然只有 3 个取值（对应 0、1、2），只是数值挪了位置、换了刻度。两步各自的目的是：

- **中心化（均值 0）**：遗传部分 `g = Σ b_j x̃_j` 的均值就是 0，不会把表型整体抬高或压低；同时 `Σ_k x̃_kj x̃_ki` 直接就是协方差（乘以 N − 1），后面算方差、相关、回归都更简单。
- **缩放（方差 1）**：让 `b²` 等于解释的方差（见下面“为什么要这样做”）。

模型里真正的正态分布有两处，都和标准化无关：噪声 `e ~ N(0, 1 − h²)` 是我们设定的（2.1 节）；z 值近似正态，是因为 z 是对很多人求和得到的，按中心极限定理趋于正态（3.5 节）。

一个 5 人的小例子：

```
原始剂量 x：        0     1     1     2     0
平均 = 0.8（p̂ = 0.4）
减去平均：        −0.8   0.2   0.2   1.2  −0.8
样本标准差 sd = sqrt( (0.64+0.04+0.04+1.44+0.64) / (5−1) ) = sqrt(0.7) ≈ 0.837
标准化 x̃：      −0.96  0.24  0.24  1.43 −0.96      （均值 0，方差 1）
```

代码里就是这两步：`Gc <- G − 2·af`（中心化），`X <- Gc / sd`（缩放），见 `simulate_bulk.R` 的 `.bulk_sample()` 和 `.bulk_trait()`。

**为什么要这样做**：

- **为了让“效应大小”和“解释多少方差”直接对应。** 如果直接用原始剂量 x，效应 β 的意思是“每多一个 a1，表型变化多少”（per-allele effect）。这个 SNP 解释的方差是 `β² · Var(x) = β² · 2p(1 − p)`，还要乘上一个和频率有关的系数。同样 β = 0.1：MAF 0.5 时解释 `0.01 × 0.5 = 0.5%`，MAF 0.05 时只解释 `0.01 × 0.095 ≈ 0.1%`。标准化以后 `Var(x̃) = 1`，解释的方差就是 `b²`，不用再管频率。
- **为了能直接按 h² 设定效应。** 我们想要的是“这个 SNP 解释 h²/K 的方差”，标准化以后只要令 `b = ±sqrt(h²/K)` 就行，不管选中的因果 SNP 是常见还是较少见，它解释的方差都正好是设定值。如果用原始剂量，就得写成 `β = ±sqrt(h²/K / (2p(1 − p)))`，每个 SNP 都要单独算，结果是一样的，只是更绕。
- **为什么在“样本内”算均值和标准差**：用这批人实际的均值和标准差，`Var(x̃)` 在这批人里正好等于 1，下一节把遗传部分的方差缩放到正好 h² 时也是在同一批人里算的，所有数字都精确对上。如果用 HWE 的理论值 `2p(1 − p)`，样本里实际的方差会有小的随机偏差（上面 5 人的例子里理论值是 0.48，实际是 0.7）。
- **标准化不改变统计检验。** 标准化只是对 x 做线性变换（减一个数、除一个数），回归的 z 值和 p 值完全不变，变的只是效应的单位。所以生成表型时用标准化的 x̃，算 summary statistics 时用中心化的原始剂量（真实研究公开的 beta 是 per-allele 的），两者给出的 z 一模一样。

### 1.3 LD 就是基因型之间的相关系数

两个 SNP 的 LD 用 `r_ij = cor(x_i, x_j)` 表示（皮尔逊相关）。`r²` 是常见的 LD 强度指标，`r` 带符号。

**符号取决于计数哪个等位基因。** 如果把 SNP i 的计数等位基因换成另一个，`x_i → 2 − x_i`，它和所有其他 SNP 的 `r` 都变号：

```
换了 SNP i 的等位基因：  r'_ij = −r_ij；两边都换：r'_ij = r_ij
一般地：r'_ij = s_i · s_j · r_ij，s = +1（不换）或 −1（换）
```

这就是为什么用参考人群算 LD 时必须先把等位基因对齐到和统计量相同的 a1（第 4 节）。对错了，LD 的符号就错，所有用 LD 的方法都会出错。

**一句话：x 是计数等位基因的拷贝数，标准化后 b² 就是方差解释比例；LD 是 x 之间的相关，符号跟着计数等位基因走。**

## 2. 表型怎么生成

### 2.1 线性模型

对一个性状、第 k 个人：

```
y_k = g_k + e_k
g_k = Σ_{j ∈ 因果 SNP} b_j · x̃_kj        （遗传部分）
e_k ~ N(0, 1 − h²)                        （噪声）
```

两个性状（GWAS 和 eQTL）用同一个模型，各用各的样本、各自的因果 SNP、各自的噪声。

**为什么是线性模型？** bulk eQTL 里每个人每个基因只有一个连续的表达量（通常还会做正态化，例如 GTEx 用逆正态变换），GWAS 的定量性状也是连续值，两者的标准分析都是“表型对剂量做线性回归”。用线性模型生成，就和真实分析用的模型一致，方法表现好坏不会被“模型设错”干扰。

**为什么噪声是正态分布？** 一是表型由大量微小因素叠加，按中心极限定理近似正态；二是 OLS 的 z 检验在正态噪声下是精确的；三是真实分析通常会把表型正态化。

**为什么是 N(0, 1 − h²)？** 两个参数分别来自两个要求：

- **均值 0**：噪声代表“除了这几个因果 SNP 以外的一切”（环境、测量误差、窗口外的基因等），它不应该让所有人的表型系统性地偏高或偏低。即使有一个整体偏移，也只会改变表型的平均值，回归时被截距吸收，对 beta、se、z 都没有影响。
- **方差 1 − h²**：我们希望表型总方差是 1，并且遗传部分正好占 h²。因为噪声和基因型无关（e 和 g 独立，没有协方差项），方差可以直接相加：

  ```
  Var(y) = Var(g) + Var(e) = h² + (1 − h²) = 1
  ⇒ Var(g) / Var(y) = h²
  ```

  所以噪声方差必须是 1 − h²，h² 才正好等于“遗传解释的比例”这个定义。例如 eQTL h² = 1.5%，噪声方差就是 98.5%：表达量的变化里只有 1.5% 来自这个窗口的因果 SNP，其余 98.5% 是噪声。这也说明为什么单个 eQTL 信号很难测：信号只占很小一部分方差。

**为什么要总方差 = 1？** 这是一个**单位的约定**，和基因型的标准化无关，也不是必须的。h² 是一个比例（遗传方差 / 总方差），z 值也不受表型单位影响（把 y 整体乘 10，beta 和 se 都乘 10，z 不变）。所以总方差取 1、取 100 都可以，结果一样。取 1 只是为了方便：此时 `Var(g) = h²`、`b² = 解释的方差比例`，不用再除以总方差。这相当于把表型也“标准化”了，真实分析里通常也会把表型标准化或正态化。

**噪声的方差是 1 − h²，不是 1。** 代码里先抽一个标准正态 `ε ~ N(0, 1)`，这只是“原材料”；再乘上 `sqrt(1 − h²)`，噪声 `e = sqrt(1 − h²) · ε` 的方差就变成 `(1 − h²) · Var(ε) = 1 − h²`（随机变量乘常数 c，方差乘 c²）。这样做等价于直接抽 `e ~ N(0, 1 − h²)`，好处是同一组 ε 可以在不同 h² 下重复使用（7.5 节的公共随机数）。代码里用的是 `sqrt(1 − Var(g))`，因为 Var(g) 已经缩放到正好 h²（2.3 节），两者相同。

### 2.2 h²（遗传度）和 per-SNP h²

**遗传度 h²** = 表型方差中由遗传解释的比例 = `Var(g) / Var(y)`。这里指的是这个 1 Mb 窗口里的**局部遗传度**，不是整个性状的遗传度（模拟里没有窗口外的遗传背景）。

**per-SNP h²**：一个性状在窗口里有 K 个因果 SNP 时，h² 平均分给它们，每个分到 `h² / K`。于是：

```
b_j = s_j · sqrt(h² / K)，   s_j 随机取 +1 或 −1（效应方向）
```

这是 8 月旧 bulk 的做法（当时 h² = 0.2，两个因果变异时各 0.1），2026-10-27 起沿用。它的含义是**固定性状在这个区域的总遗传度，因果变异越多，每个越弱**。和它对立的做法是“每个因果 SNP 固定解释一个比例”（10-23 到 10-26 那一版），那样双信号场景的总遗传度是单信号的两倍。两种做法回答的问题不同：前者比的是“同样多的遗传信号，集中在一个变异上还是分散在两个上”。

### 2.3 为什么要把 Var(g) 缩放到正好等于 h²

如果因果 SNP 之间有 LD，遗传部分的方差不等于各部分之和。以 K = 2 为例（标准化后 `Var(x̃) = 1`）：

```
Var(g) = b_1² + b_2² + 2 b_1 b_2 r_12
       = (h²/2) + (h²/2) + 2 · s_1 s_2 · (h²/2) · r_12
       = h² · (1 + s_1 s_2 r_12)
```

- 低 LD（\|r\| < 0.2）：`Var(g)` 和 h² 最多差 20%。
- 高 LD（例如 r = 0.75）：方向相同时 `Var(g) = 1.75 h²`，方向相反时只有 `0.25 h²`。

所以代码在算完 g 以后整体乘一个常数 `c = sqrt(h² / Var(g))`，让 `Var(g)` 在样本里**正好**等于 h²。这样每个场景、每个 LD 档位的总遗传度都一样，可比；噪声方差取 `1 − h²`，表型总方差约为 1。

**一个后果（冒烟测试里看到的）**：高 LD 时，单个因果 SNP 的边际信号会因为方向而差很多。两个因果 SNP r = 0.75：

```
方向相同：每个 SNP 的边际 |z| ≈ sqrt(N h² (1 + r) / 2) ≈ 7.2   （GWAS，h² = 0.3%）
方向相反：每个 SNP 的边际 |z| ≈ sqrt(N h² (1 − r) / 2) ≈ 2.7
```

（推导：方向相反时 `cov(x_1, y) = c·b·(1 − r)`，代入 `c·b = sqrt(h² / (2(1 − r)))` 得 `sqrt(h²(1 − r)/2)`。）
所以高 LD 档里“两个效应互相抵消”的情况会让信号几乎消失，这是真实存在的生物学情况，也是高 LD 档所有方法都变差的原因之一。

### 2.4 为什么固定 Var(y) ≈ 1

共定位方法和 z 值都不依赖表型的单位，把总方差定成 1 只是为了让 h² 直接等于 `Var(g)`，方便解释。

### 2.5 两组人为什么不能重叠

GWAS 的 20,000 人和 eQTL 的 1,000 人互不重叠（已按 `donors.tsv` 核对）。coloc 假设两个数据集独立：如果同一批人同时贡献两个性状，且两个表型的噪声相关，两个性状的 z 值会在没有共享因果变异时也相关，造成假的共定位证据。模拟里两性状的噪声独立、人也不重叠，和真实的 GWAS–eQTL 共定位一致。

**一句话：y = g + e；h² 是窗口内的遗传度，平分给 K 个因果 SNP，每个 b = ±sqrt(h²/K)；遗传部分再缩放到方差正好 h²。**

## 3. 统计量：从 y 到 z

### 3.1 一元回归

对每个 SNP j 单独做 y 对剂量的最小二乘回归（OLS），得到真实研究公开的 summary statistics：

```
beta_j = Σ_k x̃_kj y_k / Σ_k x̃_kj²         （x̃ 为中心化剂量）
se_j   = sqrt( RSS_j / (N − 2) / Σ_k x̃_kj² ) （RSS_j 为残差平方和）
z_j    = beta_j / se_j
p_j    = 2 · P(T_{N−2} > |z_j|)             （N 很大时 t 分布 ≈ 标准正态）
```

### 3.2 因果 SNP 的 z 值有多大（最重要的一个公式）

一元回归的 z 值和样本相关系数 ρ 的关系是 `z = sqrt(N − 2) · ρ / sqrt(1 − ρ²)`。对因果 SNP（和其他因果 SNP 低 LD 时），`ρ² ≈ per-SNP h² = h²/K`，所以：

```
因果 SNP 的期望 |z| ≈ sqrt( N · (h²/K) / (1 − h²/K) ) ≈ sqrt( N · h² / K )
```

这个量也叫非中心参数（NCP）。它把“样本量”和“效应大小”合成了一个数：**z 只取决于 N × per-SNP h²**。所以 GWAS 的 h² 0.3% 配 20,000 人，和 eQTL 的 6% 配 1,000 人，信号强度是一样的。

| | h² | N | 期望 \|z\|（K = 1） | 期望 \|z\|（K = 2） |
|---|---|---|---|---|
| GWAS | 0.1% / 0.3% / 1% / 2% | 20,000 | 4.5 / 7.7 / 14 / 20 | 3.2 / 5.5 / 10 / 14 |
| eQTL | 0.75% / 1.5% / 3% / 5% | 1,000 | 2.7 / 3.9 / 5.5 / 7.1 | 1.9 / 2.7 / 3.9 / 5.0 |

### 3.3 一个信号能不能被“看见”：功效

z 值本身有随机性：`z_c ~ N(μ, 1)`，μ 是上面的期望 \|z\|。一个因果 SNP 能被选为 lead，需要 \|z_c\| 超过 lead 阈值对应的 \|z\|：

| lead 阈值 p | 1e-3 | 1e-4 | 1e-5 | 5e-8 |
|---|---|---|---|---|
| 对应 \|z\| | 3.29 | 3.89 | 4.42 | 5.45 |

于是过阈值的概率约为 `Φ(μ − 阈值)`：

| 信号 | μ | 过 1e-3 | 过 1e-4 | 过 1e-5 |
|---|---|---|---|---|
| GWAS，h² 0.3%，K = 1 | 7.8 | ≈100% | ≈100% | ≈100% |
| GWAS，h² 0.3%，K = 2 | 5.5 | 99% | 94% | 86% |
| eQTL，h² 1.5%，K = 1 | 3.9 | 73% | 51% | 30% |
| eQTL，h² 1.5%，K = 2 | 2.7 | 29% | 13% | 5% |

**这张表就是本设定下 block-coloc 最难的地方**：eQTL 有两个因果 SNP 时，每个信号只有约 29% 的机会过 1e-3，两个都过的机会约 9%。block-coloc 要先“看见”两个信号才会切块，所以主设置下它大多数时候会退回整区域 coloc.abf。第二段把 eQTL h² 调到 3%、5%，就是为了看信号变强以后切块能不能发挥作用。

### 3.4 非因果 SNP 为什么也显著：借来的信号

非因果 SNP j 和 y 的协方差完全来自它和因果 SNP 的 LD：

```
cov(x̃_j, y) = Σ_c r_jc · b_c    （c 遍历因果 SNP）
⇒ E[z_j] ≈ Σ_c r_jc · λ_c，     λ_c = sqrt(N) · b_c ≈ 因果 SNP c 的期望 z
```

例子：因果 SNP 的 z = 20，旁边一个 r = 0.3 的 SNP，期望 z = 6，p ≈ 2e-9。它不是因果，却非常显著。

### 3.5 关键性质：z ~ N(Rλ, R)

把所有 SNP 的 z 写成向量，效应较小时：

```
z ~ N( R λ ,  R )
```

- **均值 Rλ**：λ 只在因果 SNP 上非零（大小约 sqrt(N) · b），其余 SNP 的均值是从因果 SNP 借来的（3.4 节）。
- **协方差 R**：没有任何信号时，z 之间也按 LD 相关。原因：`z_j ∝ x̃_jᵀ e`，两个 SNP 共用同一个噪声向量 e，所以 `cov(x̃_iᵀe, x̃_jᵀe) = σ² · x̃_iᵀ x̃_j = σ² N r_ij`，标准化后正好是 r_ij。

这个性质是 SuSiE-RSS、条件分析（COJO）、coloc.signals (cond) 和 block-coloc 条件 lead 选择的共同基础。它成立的前提是 **R 是产生 z 的那批人的 LD**（样本内 LD）。用参考人群的 LD 时只是近似成立（第 4 节）。

### 3.6 条件 z：怎么判断“第二个信号是不是真的”

多元正态的条件分布有现成的公式。把 z 分成已选 lead 集合 S 和待检查的 SNP j：

```
z_j | z_S ~ N( μ_j + R_jS R_SS⁻¹ (z_S − μ_S),  1 − R_jS R_SS⁻¹ R_Sj )
```

如果 j 自己没有效应、它的信号全是从 S 借来的，那么 `μ_j = R_jS R_SS⁻¹ μ_S`，条件均值就是 `R_jS R_SS⁻¹ z_S`。把它减掉再除以条件标准差：

```
z_j|S = ( z_j − R_jS R_SS⁻¹ z_S ) / sqrt( 1 − R_jS R_SS⁻¹ R_Sj )
```

- j 的信号全是借来的 → 条件 z ~ N(0, 1)，条件 p 值不显著，不计为新信号；
- j 有自己的效应 → 条件 z 的均值不为 0，仍然显著，计为**条件独立信号**（conditionally independent signal，GCTA-COJO 的说法）。

上面的例子：`z_c = 20`、r = 0.3 → 条件 z = `(6 − 0.3 × 20) / sqrt(1 − 0.09) = 0`，不是新信号。
代码里 `R_SS` 求逆前加了 1e-6 的 ridge（`cond_ridge`），防止两个 lead 高度相关时矩阵奇异。

**一句话：z ≈ sqrt(N · per-SNP h²) 决定一个信号看不看得见；z ~ N(Rλ, R) 解释了非因果 SNP 为什么也显著，也给出了条件 z 的公式。**

## 4. 给方法的 LD：1000 Genomes 参考人群

### 4.1 为什么不用样本内 LD

真实研究一般只公开 summary statistics，个体基因型是隐私，算不了样本内 LD，所以实际分析通常用参考人群的 LD。最常用的是 1000 Genomes 的欧洲人群（EUR）。本项目让所有方法、两个性状都用同一个 1000G EUR LD（chr22，489 人，GRCh37），和实际分析的条件一致。样本内 LD 只用来生成数据和定义因果 SNP 之间的 LD 档位。

### 4.2 怎么对齐

`prepare_ref_ld.R` 对每个窗口：按 rsID 和位置把 SNP 对到 1000G，等位基因相同记 `s = +1`，互换记 `s = −1`（对不上的丢掉），算参考人群的相关矩阵后乘 `s_i s_j`（1.3 节）。12 个窗口 11,850 个 SNP 里 11,794 个（99.5%）对上，没有对不上的；没对上的 56 个在模拟和分析里都去掉。

### 4.3 参考 LD 和真实 LD 差多少

r 的抽样误差约为 `(1 − r²) / sqrt(n)`。n = 489 时，r ≈ 0 的 SNP 对误差约 0.045，r = 0.5 时约 0.034。实测两者逐对的相关为 0.95–0.99，\|r\| 的中位差约 0.03，强连锁对（\|r\| > 0.3）符号全部一致。也就是说差别主要是参考人群样本小带来的抽样误差，加上两群人之间的小差异。

### 4.4 参考 LD 矩阵不满秩

一个窗口有 546–1,537 个 SNP，但参考人群只有 489 人。n 个人算出来的相关矩阵秩最多是 n − 1 = 488，所以 SNP 比人多时 R 是奇异的。这在实际分析里很常见；SuSiE-RSS 能处理，条件 z 只对少数几个 lead 求逆（加了 ridge），也没问题。

### 4.5 LD 不匹配会造成什么

这一节最重要的结论：**信号越强，LD 的小误差被放得越大。** 条件 z 的分子是 `z_j − r̂ · z_c`，如果真 r = 0.9、参考人群给的 r̂ = 0.85：

| 因果 SNP 的 z_c | j 的真实期望 z | 条件 z（用参考 LD） |
|---|---|---|
| 7.7 | 6.9 | 0.7 |
| 20 | 18 | 1.9 |
| 40 | 36 | 3.8（超过 1e-3 的 3.29，会被误当成第二个信号） |

所以在 LD 不匹配时，GWAS 信号很强的位点可能被条件分析“造出”假的第二个信号，SuSiE 也可能给出多余的 credible set。整区域 coloc.abf 完全不用 LD，不受影响。第二段把 GWAS h² 调到 1%、2%（\|z\| 14、20），正好能看到这个效应。

**一句话：实际分析只能用参考 LD；它和真实 LD 有约 0.03 的误差，信号越强误差被放得越大，依赖 LD 的方法会受影响，coloc.abf 不受影响。**

## 5. 场景和参数：每个都是为了测什么

### 5.1 场景

A、B、C、D 表示不同的因果变异。“single / double” 指每个性状的因果变异个数，“shared / distinct” 指是否共享。

| 场景 | GWAS 因果 | eQTL 因果 | 真值 | 测什么 |
|---|---|---|---|---|
| single_shared | A | A | 共定位 | 最简单的情况：不该切块，整区域 coloc.abf 就够 |
| single_double_shared | A | A, B | 共定位 | eQTL 多一个不共享的信号，可能把整区域 coloc.abf 带偏 |
| double_shared2 | A, B | A, B | 共定位 | 两个信号都共享 |
| double_shared1 | A, B | A, C | 共定位 | 两边各有一个不共享的信号，只共享 A |
| single_distinct | A | B | 不共定位 | 单信号阴性 |
| double_distinct | A, B | C, D | 不共定位 | 多信号阴性：检验切块会不会制造误报 |
| gwas_only | A | （无） | 不共定位 | 额外阴性：只有 GWAS 有信号 |
| null_both | （无） | （无） | 不共定位 | 额外阴性：都没有信号 |

前 4 个和 Wallace (2021) Fig 1 的 4 行对应（single_distinct、single_shared、single_double_shared、double_shared2）；double_shared1、double_distinct 来自 8 月旧 bulk。

**判定线只用 single_distinct 和 double_distinct 定**（两个性状都有信号但不共享，这是共定位方法最该区分的阴性）。gwas_only、null_both 只用冻结的判定线报告误报率，不参与定线，也不并入总的检出率、误报率和 AUC。

### 5.2 因果 SNP 之间的 LD 档位

| 档位 | 那一对因果 SNP 的 \|r\| | r² | 方法会怎样 |
|---|---|---|---|
| 低（主设置） | < 0.2 | < 0.04 | 两个因果成为两个独立 lead，各自成块 |
| 中 | 0.32–0.63 | 0.1–0.4 | 第二个 lead 会被 clump 去掉（r² ≥ 0.1），但又不在第一个 lead 的邻域里（r² < 0.4） |
| 高 | 0.63–0.9 | 0.4–0.81 | 两个因果落进同一个块 |

切点 0.32、0.63 来自方法的两个阈值：clump r² = 0.1 → \|r\| = 0.316；邻域 r² = 0.4 → \|r\| = 0.632。所以分档正好测的是算法行为发生变化的地方。上限 0.9：LD 更高的两个 SNP 几乎无法区分，所有方法都会失败，没有比较的意义。
“那一对”是同一性状里的两个因果（double_distinct 的 A–B、C–D；double_shared1 的 A–B、A–C），其他不同因果之间要求 \|r\| < 0.2。double_shared1 在中、高档是例外：B、C 都和 A 强连锁时，B–C < 0.2 在真实窗口里几乎抽不到，所以只要求 B–C 低于该档上限。

## 6. 方法怎么从 summary statistics 算出 PP4

### 6.1 coloc.abf（所有方法的基础）

coloc.abf 对一个区域同时考虑五个假设：

| 假设 | 含义 |
|---|---|
| H0 | 两个性状在区域内都没有因果变异 |
| H1 | 只有性状 1 有 |
| H2 | 只有性状 2 有 |
| H3 | 两个都有，但是**不同的**变异 |
| H4 | 两个都有，而且是**同一个**变异（共定位） |

它假设**每个性状在区域内至多一个因果变异**。这条假设是整个项目的出发点。

**第一步：每个 SNP 的贝叶斯因子（Wakefield 近似 BF）。** 对 SNP j，比较“有效应（效应 ~ N(0, W)）”和“没有效应”两个模型下观测到 beta 的概率：

```
ABF_j = N(β̂; 0, V + W) / N(β̂; 0, V) = sqrt(1 − r) · exp( r · z² / 2 )
V = se_j²，  W = (0.15 · sdY)²（连续性状的默认先验），  r = W / (W + V)
```

z 越大，ABF 指数增长。数量级（MAF 0.3，sdY = 1）：

| 信号 | z | ABF |
|---|---|---|
| GWAS 单信号 | 7.75 | 约 7 × 10¹¹ |
| GWAS 双信号之一 | 5.48 | 约 2 × 10⁵ |
| eQTL 单信号 | 3.87 | 约 270 |
| eQTL 双信号之一 | 2.74 | 约 9 |
| 没有信号 | ~N(0,1) | 平均约 1 |

（最后一行：z 是标准正态时，`E[exp(r z²/2)] = 1/sqrt(1 − r)`，所以 ABF 的期望正好是 1。）

**第二步：五个假设的后验。** 记 `A1_j`、`A2_j` 为两个性状在 SNP j 的 ABF：

```
H0 ∝ 1
H1 ∝ p1 · Σ_j A1_j
H2 ∝ p2 · Σ_j A2_j
H3 ∝ p1 · p2 · Σ_{j ≠ k} A1_j · A2_k
H4 ∝ p12 · Σ_j A1_j · A2_j
PP4 = H4 / (H0 + H1 + H2 + H3 + H4)
```

H4 要求**同一个 SNP** 在两个性状上的 ABF 都大；H3 是“不同 SNP”的所有组合。

**几个能手算的结论**（一个窗口 1,000 个 SNP，没有 LD 的简化例子）：

1. **H4 对 H3**：`H4 / H3 ≈ (p12 / (p1 p2)) × A2_共享 / Σ_{其他} A2 = 1000 × A2_共享 / Σ_{其他} A2`。先验让“共享”比“不同”高 1000 倍，所以只要共享 SNP 在性状 2 上有一点证据，H4 就压过 H3。
2. **H4 对 H1**：`H4 / H1 ≈ (p12 / p1) × A2_共享 = 0.1 × A2_共享`。eQTL 信号弱时 A2 小，PP4 主要输给 H1（“只有 GWAS 有信号”）。
3. 代入数字（GWAS z = 7.75）：

| eQTL 在共享 SNP 上的 z | PP4 | PP1 | PP3 |
|---|---|---|---|
| 3.87（单信号） | 0.96 | 0.04 | 0.004 |
| 2.74（双信号时每个的强度） | 0.46 | 0.49 | 0.05 |
| 0（eQTL 没信号，即 gwas_only） | 0.08 | 0.83 | 0.08 |

第二行说明为什么 h² 平分以后双信号场景会难很多；第三行说明为什么 gwas_only 的 PP4 不是 0 而是约 0.04–0.09，它会越过很低的判定线（上一版判定线约 0.1，所以 gwas_only 误报约 10%）。

4. **single_double_shared 的失败**：eQTL 有共享 A 和特有 B。若 A 的 z = 3.0、B 的 z = 4.5，上面的简化例子给出 PP4 ≈ 0.57、PP3 ≈ 0.12；反过来（A 4.5、B 3.0）PP4 ≈ 1.00。真实 LD 下，信号会分散到连锁的 SNP 上，差距更大（上一版主设置：特有信号更强时整区域 coloc.abf 的 PP4 中位数只有 0.32）。这就是 block-coloc 想解决的问题：把 B 切到另一个块里，A 所在的块里只剩一个信号，单因果假设重新成立。

### 6.2 coloc.susie

1. 对每个性状用 SuSiE-RSS（`susie_rss(z, R, n)`）做精细定位。SuSiE 把效应写成 L 个“单效应”之和，每个单效应恰好落在一个 SNP 上（落在哪个 SNP 有后验概率），用迭代算法估计。每个单效应给出一个 95% credible set：一组 SNP，因果变异在其中的后验概率 ≥ 95%。
2. 对两个性状的每一对 credible set，用 SuSiE 给的逐 SNP 贝叶斯因子跑一次 coloc（和 6.1 一样的五假设计算），得到这一对的 PP4。
3. 取所有对中最大的 PP4。

所以 coloc.susie 天然允许多个因果变异。代价有两个：需要 LD（`z ~ N(Rλ, R)` 是它的似然，LD 不匹配会出问题）；信号太弱时找不到 credible set，就没有结果。冒烟测试里 264 个位点有 194 个 eQTL 没有 credible set（其中 47 个两个性状都没有）。
`susie_raw`：找不到就记为无结果（判为不共定位）。`susie_fallback`：找不到就退回整区域 coloc.abf，这是实际使用中的常见做法。

### 6.3 coloc.signals

先在每个性状里找多个信号，再对每一对信号跑 coloc.abf，取最大 PP4。找信号有两种方式：

- **cond**：逐步条件分析（3.6 节的公式），每次把最强的信号作为条件，看剩下有没有新的显著信号，最多 3 个；
- **mask**：找到一个信号后，把和它 r² > 0.01 的 SNP 都屏蔽掉，再在剩下的 SNP 里找下一个。

它和 block-coloc 的思路最接近，区别在于它对每个信号对都做了条件化或屏蔽，而 block-coloc 是按 LD 把区域切块。

### 6.4 block-coloc 的三个版本

共同的步骤：

```
1. 找 lead：p 值低于阈值的 SNP，按 p 从小到大贪心 clump（和已选 lead 的 r² < 0.1 才能入选）
2. 决定要不要切块（三个版本在这里不同）
3. 切块：每个 lead 的邻域 = 和它 r² ≥ 0.4 的 SNP；两个性状的邻域有重叠就连起来，
         按连通分量合成块；块里 lead 的效应方向不一致时拆开
4. 每个块里跑 coloc.abf，取 PP4 最大的块
```

| 版本 | 什么时候切块 | 怎么数 lead |
|---|---|---|
| 条件 lead 选择（本文方法） | 两个性状都有 ≥ 1 个 lead，且至少一个性状有 ≥ 2 个；否则跑整区域 coloc.abf | 第 2 个及以后的 lead 必须在“以已选 lead 为条件”后仍显著（3.6 节） |
| 边际 lead 选择 | 同上 | 只看边际 p 值和 clump，不做条件分析 |
| 交接包原版（对照） | 两个性状都有 lead 就切（不足时用 top-5 补位）；只有一个 lead 时取 max(块, 整区域) | 边际 |

**为什么要“至少一个性状有 ≥ 2 个 lead 才切块”**：两个性状都只有一个信号时，coloc.abf 的单因果假设成立，切块没有好处，只会多出“块太小、信号被切掉”的风险。Wallace (2021) 也发现真单因果时整区域 coloc 表现最好。
**为什么要条件 lead 选择**：信号强时，因果 SNP 旁边 r² 在 0.04–0.1 之间的 SNP 也会显著（3.4 节），clump 去不掉，边际计数会把它当成第二个信号，误切块。条件分析能识别出它只是借来的信号。
**交接包原版的问题**：补位会在没有信号的性状上用噪声造出 lead；取 max(块, 整区域) 会系统性抬高 PP4，误报随之增加。

**一句话：所有方法最后都是在某个 SNP 集合上跑 coloc.abf 式的五假设计算；区别在于怎么处理“一个性状有多个信号”——SuSiE 拆成单效应，signals 条件化或屏蔽，block-coloc 按 LD 切块，并且只在确有多个信号时才切。**

## 7. 实验逻辑：为什么这样评价

### 7.1 为什么用模拟

真实数据不知道哪些位点“真的”共定位，没法算检出率和误报率。模拟时因果 SNP 是我们放的，每个位点都有标准答案。代价是结果只能解读为“方法在真实 LD 结构、这种生成模型下的表现”，不对应任何真实基因或疾病。所以模型要尽量像真实分析：真实基因型、线性模型、参考人群 LD。

### 7.2 为什么分校准窗口和测试窗口

判定线和 lead 阈值都是从数据里“调”出来的。如果在同一批数据上调参再报告结果，结果会偏乐观（和机器学习里在训练集上报告准确率一样）。所以：

```
6 个校准窗口：定每个方法的 PP4 判定线、block-coloc 的 lead 阈值
   ↓（冻结，不再改）
6 个测试窗口：报告所有结果
```

测试窗口的 LD 结构是方法没“见过”的，结果更可信。

### 7.3 为什么比“相同误报率下的检出率”，而不是 PP4 > 0.8

不同方法的 PP4 刻度不一样：同样是“不共定位”的位点，有的方法给 0.02，有的给 0.2。如果都用 PP4 > 0.8，一个方法检出多，可能只是因为它整体给分偏高、误报也多。公平的比法是先让每个方法的误报率相同，再比谁检出更多。这就是 ROC 曲线上的一个点。

**判定线怎么定**：在校准窗口里，把阴性位点（single_distinct、double_distinct）的 PP4 从大到小排，取第 `⌊0.05 × n⌋ + 1` 个作为判定线 t，PP4 > t 判为共定位。这样阴性里最多 5% 越过它。

**lead 阈值怎么选**：block-coloc 每个版本在 1e-3、1e-4、1e-5 中各算一遍，选校准窗口上（误报率 5% 时）检出率最高的那个；并列时取 1e-3。

**无结果怎么算**：方法没给出 PP4（例如 coloc.susie 找不到 credible set），算作“判为不共定位”，分母始终是全部位点。否则一个经常不给结果的方法会因为只在容易的位点上作答而显得很好。

另外也报告 **AUC**（随机取一个阳性和一个阴性，阳性 PP4 更高的概率），它不依赖判定线，反映整体区分能力。

PP4 分布图（第 4 页）把这件事画出来：每个方法一个小图，虚线是它的判定线，线以上的绿点比例是检出率，红点比例是误报率。

### 7.4 置信区间和检验

- **Wilson 区间**（比例的 95% 区间）：

  ```
  ( p̂ + z²/2n ± z · sqrt( p̂(1 − p̂)/n + z²/4n² ) ) / (1 + z²/n)，  z = 1.96
  ```

  比常见的 `p̂ ± 1.96 sqrt(p̂(1−p̂)/n)` 在比例接近 0 或 1 时更准（误报率就在 0–10% 附近）。

- **McNemar 配对检验**：所有方法用的是**同一批位点**。比较两个方法时，只有“一个判对、一个判错”的位点（不一致对）带信息。设 b10 = 方法 1 对、方法 2 错的个数，b01 反之，在两方法一样好的原假设下 b10 ~ Binomial(b10 + b01, 0.5)，用精确二项检验。配对比不配对灵敏得多，因为位点本身的难易被抵消了。

- **AUC 的区间**：对位点做 1,000 次有放回重抽样（阳性、阴性分别抽），取 2.5% 和 97.5% 分位数。

- **精度量级**：测试窗口每个场景 600 个位点，检出率 90% 时标准误约 1.2 个百分点；校准阴性 1,200 个，误报率 5% 时标准误约 0.6 个百分点。所以方法之间 2–3 个百分点的差距，单独看比例区间会重叠，但配对检验可能显著。

### 7.5 公共随机数：为什么不同强度之间可以直接比

同一个（窗口、场景、重复）下，两个性状的噪声向量固定；同一个 LD 档位下，因果 SNP 和效应方向也固定。改变 h² 时只有 h² 变，其余一模一样。这样强度之间的差别来自 h² 本身，不是换了一批随机数带来的波动，曲线更平滑，配对比较更有效。种子由（窗口、场景、重复、用途）算出，任何人重跑都得到同样的结果。

### 7.6 两段实验

- **第一段（主设置）**：GWAS h² 0.3%、eQTL h² 1.5%、因果之间低 LD。每个窗口 × 8 场景 × 100 次。在这里定判定线和 lead 阈值，回答“主设置下谁好”。
- **第二段（一次只变一个因素）**：从主设置出发，只改 GWAS h²（0.1%–2%）、或只改 eQTL h²（0.75%–5%）、或只改因果间 LD 档位。每格 50 次。**沿用第一段的判定线，不重新调**，所以误报率会偏离 5%，这是故意的：看同一条判定线在条件变化时是否稳健（实际使用中也不可能每个位点重新调线）。
- **额外阴性**：gwas_only、null_both 用冻结的判定线报告误报率，检查“只有一个性状有信号”时会不会误报。

### 7.7 读结果时要问的问题

1. 误报率匹配到 5% 时，本文方法的检出率比整区域 coloc.abf、coloc.susie + fallback 高还是低？差距的配对检验显著吗？
2. 提升来自哪个场景？在 single_shared 上有没有损失？
3. 它切块切得对不对：单信号场景走 block 的比例应接近 0，多信号场景应尽量高（第 4 页的分支表）。
4. 多信号但没切块时，是因为第二个信号太弱过不了阈值（3.3 节的功效表），还是别的原因？
5. 第二段：GWAS 变强时误报率稳不稳（4.5 节的 LD 不匹配效应）？eQTL 变强时切块能不能发挥作用？高 LD 时谁崩得最厉害？

**一句话：用模拟知道答案；校准和测试分开，避免调参偏乐观；在相同误报率下比检出率，配对检验比方法；公共随机数让不同条件之间可比。**

## 8. 自测题

1. GWAS 20,000 人、某因果 SNP 的 per-SNP h² = 0.2%，期望 \|z\| 是多少？过 5e-8 的概率大约多少？
2. eQTL h² = 3%、有两个因果 SNP、彼此低 LD，每个的期望 \|z\| 是多少？
3. 某 SNP 和一个 z = 12 的因果 SNP 的 r = 0.25，它自己没有效应。它的期望 z 是多少？会不会被 clump（r² < 0.1）去掉？以因果 SNP 为条件后它的期望 z 是多少？
4. 为什么换了计数等位基因以后 LD 要变号？如果参考人群里某个 SNP 的等位基因是反的、但忘了翻转，条件 z 会出什么问题？
5. 为什么 gwas_only 的 PP4 大约是 0.08，而不是 0？用 H4/H1 的近似式说明。
6. 为什么不能直接用 PP4 > 0.8 比较方法？
7. 判定线为什么在校准窗口上定、在测试窗口上报告？
8. 为什么两个方法比较用 McNemar 检验，而不是比较两个比例的区间是否重叠？
9. 两个因果 SNP r = 0.75、效应方向相反、h² = 0.3%、N = 20,000，每个的边际 \|z\| 大约是多少？为什么？
10. 为什么 h² 平分以后，主设置下 block-coloc 大多数时候不切块？

## 9. 答案

1. `sqrt(20000 × 0.002) ≈ 6.3`；5e-8 对应 \|z\| = 5.45，`Φ(6.3 − 5.45) = Φ(0.85) ≈ 80%`。
2. per-SNP h² = 1.5%，`sqrt(1000 × 0.015) ≈ 3.9`。
3. 期望 z = 0.25 × 12 = 3，p ≈ 0.003，接近 1e-3 的门槛；r² = 0.0625 < 0.1，clump 去不掉；条件后 `(3 − 0.25 × 12) / sqrt(1 − 0.0625) = 0`。
4. 剂量从 x 变成 2 − x，和其他 SNP 的相关系数变号。忘了翻转时，条件 z 的分子 `z_j − r z_c` 会变成 `z_j + abs(r) · z_c`，借来的信号不但没减掉反而加倍，会造出假的条件独立信号；SuSiE 等也会给出错误结果。
5. eQTL 没有信号时，GWAS 信号所在 SNP 的 A2 平均约 1，`H4/H1 ≈ (p12/p1) × A2 = 0.1`，再加上 H3 约为 H1 的 0.1，PP4 ≈ 0.1 / (1 + 0.1 + 0.01) ≈ 0.09。
6. 各方法 PP4 的刻度不同，固定 0.8 时，检出多的方法可能只是误报也多。要先把误报率对齐再比检出率。
7. 判定线和 lead 阈值是从数据里调出来的，在同一批数据上调参再报告会偏乐观；测试窗口是“没见过”的数据。
8. 所有方法用同一批位点，配对检验只看不一致的位点，抵消了位点本身的难易，比两个独立比例的比较灵敏得多。
9. 约 2.7。方向相反时两个效应在 LD 下互相抵消：`abs(z) ≈ sqrt(N h² (1 − r)/2) = sqrt(20000 × 0.003 × 0.25 / 2) ≈ 2.7`。
10. 双信号时 eQTL 每个信号的期望 \|z\| 只有 2.7，过 1e-3 的概率约 29%，两个都过的概率约 9%。block-coloc 要看到 ≥ 2 个 lead 才切块，所以大多数多信号位点会退回整区域 coloc.abf。

| 术语 | 含义 |
|---|---|
| dosage | 计数等位基因的拷贝数，0/1/2 |

| NCP | 非中心参数，因果 SNP 的期望 z |
| lead | p 值低于阈值、经过 clump 的代表性 SNP |
| clump | 按 p 值贪心挑 lead，去掉和已选 lead 高度连锁的 SNP |
| 条件独立信号 | 以已选 lead 为条件后仍显著的信号 |
